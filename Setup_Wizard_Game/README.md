# Setup Wizard Game

A fun, interactive game built with Processing where you play as a wizard defending the digital realm!

## Requirements to Run

To run this `.pde` file, you need:

- **Processing IDE** - Download for free at [processing.org](https://processing.org/download)
- A keyboard (WASD for movement, P to fire)
- Optional: A mouse (for the "Play Again" button)

## How to Play

1. Download and install [Processing](https://processing.org/download)
2. Open the `setup_wizard.pde` file in Processing
3. Click the **Play** button (or press Ctrl+R on Windows/Linux, Cmd+R on macOS)

## Game Controls

- **W** - Move up
- **A** - Move left
- **S** - Move down
- **D** - Move right
- **P** - Fire fireballs

## Game Objective

Shoot fireballs at the corrupted code target to debug it. Each hit teleports the target and advances it downward. Collect coins spawned after each hit to increase your score. Avoid the falling enemies!

## About

This is the Setup Wizard, master of user experience and vanquisher of evil Terminal UIs, ready to defend the digital realm with magical code and precision fireballs.

Good luck! 🧙‍♂️
